Hola! Aquí están las instrucciones para guiarse en el programa:

core: contiene los contenidos del código que ejecuta el programa en sí, como las matrices, los puntos 1, 2 y 3 etc.

ui: contiene app.py, que es una interfaz hecha con Tkinter. Es básicamente lo que despliega el programa.

manim: contiene las animaciones realizadas para el video, todo hecho en Python! Es una herramienta bastante útil y divertida de usar.
